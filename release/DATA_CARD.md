# Columnist data

Chart ids, labels and sources. No .osu files, replays or audio.

- Labels (10,205 charts): `charts.csv`, `labels.csv`, `labels_wide.csv`, `sources.csv`: tournament slots, 11 pattern categories, 20 user tags, with a song-grouped 5-fold split.
- The model was pretrained on 62,161 unlabelled 4K charts (59,361 unique) selected by mapper record; the chart-id list is not part of this first release.
- Charts can be re-fetched from osu! with your own API key; scripts are in the code repository.
- Use of osu! data complies with fair research use.
