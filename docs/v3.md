# Deep v3 (4K): one sequence network plus statistics heads

Written 2026-11-05. Everything below is scored out-of-fold on the 26k 4K charts of the 5 song-grouped folds
(`data/v2_folds.csv`), strict v6 labels (staff + user tags, Komi's jack mapping), SV gate applied.
`scripts/compare_v3.py` compares a run with deep v2 (`deep_fullS`, mean of two seeds) with a paired bootstrap over songs.

## Pipeline
* **Sequence network** (`osu_patterns/deep/v3.py`, `scripts/train_v3.py`). Row tokens from a 256-item vocabulary
  (none / head / tail / held per column), log-scale sin/cos timing of the gaps (ms only, no snaps or BPM grid),
  conv stem, time-biased block-local attention (+-2 s), window-level attention-MIL (`--win-mil`), a whole-chart
  timing/scroll summary path. Stage 1: masked rows + light stats regression + task BCE where labelled, with the fold-k
  teacher's soft labels where unknown (the teacher is a data step); stage 2: labelled charts, early stopping.
  The same class with `--causal` is the live Lens network (per-event scores depend only on the past).
* **Statistics heads** (`scripts/stat_heads.py`). One boosted tree per task on `data/all_features.csv.gz` (+ reading
  features) for the tasks that are characteristics of the whole chart: TB, Stamina, streams/stamina, Reading, Memo,
  slider tags. A pure sequence net can't learn these from a few hundred positives.

## Results (categories / tags mean AP)
| run | categories | tags |
|---|---|---|
| deep v2 (fullS) | 0.738 | 0.591 |
| v3a pure sequence, event-MIL | 0.681 | 0.577 |
| v3b + chart summary | 0.704 | 0.586 |
| v3c + 4 s bin path | 0.703 | 0.583 |
| v3d + hand-built wide inputs + teacher | 0.728 | 0.594 |
| v3e window-MIL + summary + teacher | 0.728 | 0.592 |
| **v3g = v3e + statistics heads** | **0.750** | **0.598** |

v3g is significantly better than v2 on Chordjack, Reading, TB, quadstream, speedjack, longjack and significantly
worse on nothing. The causal network (folds 0,1) scores 0.728 / 0.587 against 0.754 / 0.581 for v2 on the same folds;
its deficit is TB only, which the heads cover.

## v2 -> v3 ablations (v2 recipe, folds 0,1; reference 0.754 / 0.581)
no teacher 0.740 / 0.556; no masked-window loss 0.752 / 0.579; 4K only 0.745 / 0.578; no window transformer
0.754 / 0.588. Only the teacher matters. v3 under v2's recipe (teacher, 30 epochs): 0.713 / 0.585, with window-MIL
0.720 / 0.584; the remaining gap is TB, Stamina and SV, i.e. chart-level statistics.

## Reproduce
```
python scripts/train_v3.py --name v3e --extra data/unranked_4k_kept.csv --device cuda --amp --tta \
    --no-bins --win-mil --teacher --stage1-epochs 30 --patience 6
python scripts/stat_heads.py
python scripts/compare_v3.py v3g deep_fullS_s0 deep_fullS_s1      # after merging the head columns (see logs/)
```
